Cài đặt SOC Agent trên máy trạm

Sao chép thư mục soc_agent/ sang máy cần giám sát, tạo tệp config.json rồi chạy. Agent sẽ tự đăng ký bằng enrollment token và nhận API key riêng.

Enrollment token: {{ enrollment_token }}   Server URL: {{ server_url }}

Windows (PowerShell, chạy với quyền Administrator để đọc Security log):

cd soc_agent
python agent.py --server {{ server_url }} --token {{ enrollment_token }} --register
python agent.py            # chạy liên tục; hoặc cài thành dịch vụ: install\install_windows_task.ps1

Linux (Ubuntu/Debian/CentOS):

cd soc_agent
sudo python3 agent.py --server {{ server_url }} --token {{ enrollment_token }} --register
sudo python3 agent.py      # hoặc: sudo cp install/soc-agent.service /etc/systemd/system/ && sudo systemctl enable --now soc-agent

Windows Server 2003 trong lab (bộ đọc WMI riêng):

Sao chép soc_agent/legacy_windows2003.vbs vào C:\soc_agent. Chạy bằng tài khoản quản trị trong máy ảo. Bộ đọc này dùng WMI có sẵn, giữ nguyên Event ID cũ và không cần Python hoặc wevtutil.

cd /d C:\soc_agent
cscript //nologo legacy_windows2003.vbs {{ server_url }} {{ enrollment_token }} --once
cscript //nologo legacy_windows2003.vbs {{ server_url }}

Bước --once đăng ký lần đầu và kiểm tra gửi log. Khi thành công, chạy lệnh thứ hai để thu thập liên tục. Không chạy đồng thời hai bản. Bộ đọc WMI dành cho lab, chỉ nạp tối đa 5 log gần nhất mỗi kênh ở lần đầu; các lần sau đọc tiếp theo checkpoint.

Mặc định agent thu thập: Windows (Security, System, Application) · Linux (/var/log/auth.log hoặc /var/log/secure, /var/log/syslog hoặc /var/log/messages, journald). Có thể thêm tệp log tùy ý (Nginx/Apache access log...) trong config.json.
